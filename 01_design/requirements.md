# 要件整理

## 基本コンセプト

- 自分が使用しているランニングシューズの写真・距離などを記録できること
  - 距離以外の詳細項目（購入日、使用開始日、累計距離の上限目安など）は今後決定
- 写真からアニメーション表示ができること（本アプリの特徴としたい）

## 競合調査を踏まえた方針（詳細: [competitor_research.md](./competitor_research.md)）

- Nike Run Club／adidas Running／ASICS Runkeeper／Strava はいずれも「ランニング記録アプリ」が主機能で、シューズ管理はその付随機能にすぎない
  → 本アプリは **シューズ管理・愛着形成に特化** した立ち位置とし、ランニング記録アプリへの対抗ではなく棲み分けを図る
- 各社とも走行距離の累計記録・買い替え通知（目安500km前後）・複数シューズのコレクション管理が共通機能
  → 最低限の記録機能（距離・写真）としてこれらを踏襲しつつ、まずは手動入力ベースで実装する（外部サービス連携は後回し）
- Strava／Runkeeper は「アクティビティごとに使用シューズを手動選択」する運用で、選び忘れによる精度低下が弱点
  → 本アプリは記録のハードルを下げるシンプルな入力導線を意識する
- 写真は静止画コレクション表示が主流で、アニメーション表示をしている競合は見当たらない
  → **写真からのアニメーション表示** を最大の差別化ポイントとして位置づける

## 今後の検討事項

- 記録項目の詳細（距離・日付・メモ・シューズの状態など）
- 走行距離の目安（500km等）を基にした買い替えアラート機能を実装するか判断
- 写真アニメーションの実現方式（CSS アニメーション／Lottie／その他）
- 上記を踏まえて画面設計・データモデル設計を進める
